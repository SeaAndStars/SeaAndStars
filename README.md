## 🌊 About

> If the tool I need doesn't exist, I write it — usually in C#.

- 🛠️ **Desktop toolsmith** — C# / .NET 10 on two tracks: Fluent-style Windows utilities with WPF, and cross-platform desktop apps on Avalonia for Windows + Linux
- 📖 **Manga toolchain** — [LabelPlus Next](https://github.com/SeaAndStars/LabelPlus_Next), a cross-platform workbench for labeling, translation, collaboration and safe release, backed by the [Poprako](https://github.com/SeaAndStars/poprako) team platform
- 🎞️ **Video quality nerd** — [VideoQuality](https://github.com/SeaAndStars/VideoQuality) scores encodes frame by frame with libvmaf + CUDA and lets you *see* the difference in a frame-exact player
- 🎮 **Game tooling** — osu! auto-host-rotation bot, Master Duel account switcher, N2N LAN GUI: every one of them started as "I need this and nobody made it"
